# 🎓 Student Finance Manager

A simple and effective web application to help students track their income, expenses, and manage their monthly budget.

## Features

✅ **Income & Expense Tracking** - Log all your financial transactions  
✅ **Monthly Budget Management** - Set a budget and monitor spending  
✅ **Visual Progress Bar** - See your budget usage at a glance  
✅ **Transaction Filtering** - Filter by type (income/expense) or search by description  
✅ **Data Persistence** - All data is saved locally using browser localStorage  
✅ **Responsive Design** - Works on desktop, tablet, and mobile devices  
✅ **Delete Transactions** - Easily remove any transaction  

## How to Use

1. **Open the app** - Simply open `index.html` in your web browser
2. **Set Your Budget** - Enter your monthly budget amount in the "Monthly Budget" section
3. **Add Transactions** - Fill in the form with:
   - Type (Income or Expense)
   - Description (e.g., "Part-time job", "Textbooks")
   - Amount
   - Date
4. **View Summary** - Check your total income, expenses, and balance at the top
5. **Monitor Budget** - The progress bar shows how much of your budget you've spent
6. **Filter & Search** - Use the filter options to view specific transactions

## Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling and animations
- **Vanilla JavaScript** - Functionality and logic
- **LocalStorage API** - Data persistence

## Installation

No installation required! Just:
1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. Start tracking your finances!

## Data Storage

All your data is stored locally in your browser's localStorage. Your data:
- ✅ Never leaves your device
- ✅ Persists between browser sessions
- ✅ Is cleared only when you clear browser data

## Browser Support

Works on all modern browsers:
- Chrome/Chromium
- Firefox
- Safari
- Edge
